# PDF CSS Customization Reference

The `generate-pdf.sh` script embeds a print-optimized CSS stylesheet. Override or extend these styles to customize the PDF output.

## Default Page Layout

```css
@page {
  size: letter;           /* US Letter (8.5 x 11 in) */
  margin: 1in 0.75in;    /* Top/bottom 1in, left/right 0.75in */
  @bottom-center {
    content: counter(page);
    font-size: 10pt;
    color: #666;
  }
}
```

### Alternative Page Sizes

| Size | CSS value | Dimensions |
|------|-----------|------------|
| US Letter | `letter` | 8.5 x 11 in |
| A4 | `A4` | 210 x 297 mm |
| Legal | `legal` | 8.5 x 14 in |

## Typography

The default font stack uses system fonts for broad compatibility:

```css
body {
  font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Helvetica, Arial, sans-serif;
  font-size: 11pt;
  line-height: 1.6;
}
```

### Custom Fonts

To use custom fonts, install them on the system (weasyprint reads system fonts) and update the `font-family` in the CSS. Common technical documentation fonts:

- **Source Sans Pro** / **Source Serif Pro** - Adobe's open-source families
- **Inter** - Clean sans-serif with good readability
- **JetBrains Mono** - Code font with ligatures

## Heading Styles

```css
h1 {
  font-size: 22pt;
  margin-top: 2em;
  page-break-before: always;      /* Each chapter starts on new page */
  border-bottom: 2px solid #333;
  padding-bottom: 0.3em;
}
h1:first-of-type {
  page-break-before: avoid;       /* Don't break before first heading */
}
h2 { font-size: 16pt; border-bottom: 1px solid #ccc; }
h3 { font-size: 13pt; }
```

## Code Blocks

```css
pre {
  background: #f6f8fa;
  border: 1px solid #e1e4e8;
  border-radius: 6px;
  padding: 12px;
  font-size: 9pt;
  line-height: 1.45;
  overflow-wrap: break-word;    /* Prevent code from overflowing margins */
  white-space: pre-wrap;
}
code {
  font-family: "SF Mono", "Fira Code", Menlo, monospace;
  font-size: 9.5pt;
  background: #f4f4f4;
  padding: 1px 4px;
  border-radius: 3px;
}
```

## Table of Contents

The TOC is generated by pandoc and styled separately:

```css
nav#TOC {
  page-break-after: always;    /* TOC on its own page(s) */
}
nav#TOC h2 { font-size: 18pt; }
nav#TOC ul { list-style: none; padding-left: 0; }
nav#TOC li { margin: 0.3em 0; }
nav#TOC ul ul { padding-left: 1.5em; }
```

## Tables

```css
table {
  border-collapse: collapse;
  width: 100%;
  font-size: 10pt;
}
th { background: #f0f0f0; font-weight: 600; }
tr:nth-child(even) { background: #fafafa; }
th, td { border: 1px solid #ddd; padding: 6px 10px; }
```

## Customizing the Script

To override the embedded CSS, modify the `cat > "$CSS_FILE"` heredoc in `generate-pdf.sh`. Alternatively, create a custom CSS file and pass it to weasyprint separately:

```bash
weasyprint --stylesheet custom.css input.html output.pdf
```

## Color Themes

### Dark Header Theme

```css
h1 { background: #2d3748; color: white; padding: 0.5em; border: none; }
h2 { border-bottom: 2px solid #4a5568; }
```

### Minimal Theme

```css
h1 { border-bottom: none; font-weight: 300; font-size: 28pt; }
h2 { border-bottom: none; font-weight: 400; }
pre { border: none; background: #fafafa; }
```

## Print-Specific Tips

- Use `page-break-inside: avoid` on elements that should not split across pages
- Use `page-break-before: always` to force page breaks
- Avoid using viewport-relative units (vh, vw) in print CSS
- Test with weasyprint locally before generating final output; rendering differences between browsers and weasyprint are common
