# output-styles

Custom Claude Code output styles.

## Styles

- **Laconic** (`output-styles/laconic.md`): fewest words that keep the full meaning. Adapted from [zieka/ike](https://github.com/zieka/ike) (MIT, © 2026 Kyle Scully).

## Usage

Run `/output-style` and pick the style, or set `"outputStyle"` in settings.
